# Финансовый кабинет

Личный кабинет финансовой отчётности: доходы, расходы и активы.

## Возможности

- **Обзор** — баланс, доходы и расходы за текущий месяц, стоимость активов, графики движения средств за 6 месяцев, структура расходов и состав активов, последние операции.
- **Доходы** — таблица записей с категориями, датами и суммами; добавление, редактирование и удаление.
- **Расходы** — аналогичная таблица расходов по категориям.
- **Активы** — учёт активов (деньги, недвижимость, транспорт, ценные бумаги и др.) с их стоимостью.
- **Экспорт** — выгрузка всех данных в JSON для резервной копии.

Данные хранятся локально в браузере (localStorage) — ничего не отправляется на сервер.

## Запуск

Статический сайт без сборки. Достаточно открыть `index.html` в браузере или запустить любой локальный сервер:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Структура

- `index.html` — разметка и модальное окно добавления записей
- `styles.css` — тёмная тема, адаптивная вёрстка
- `app.js` — вся логика: хранилище, таблицы, графики (Chart.js с CDN)
